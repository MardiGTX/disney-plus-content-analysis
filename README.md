## 📌 Gambaran Proyek

Proyek ini bertujuan melakukan **analisis data konten Disney+** untuk memahami pola distribusi konten, tren perilisan, genre, kategori, serta karakteristik konten yang tersedia pada platform Disney+.

Analisis dilakukan melalui proses **data cleaning, exploratory data analysis (EDA), statistik deskriptif, statistik inferensial menggunakan Chi-Square Test**, dan visualisasi data untuk menemukan insight dari dataset.

Selain itu, visualisasi data juga digunakan untuk membantu memahami pola distribusi konten dan mendukung interpretasi hasil analisis.

---

## 🎯 Tujuan Proyek

- Melakukan eksplorasi dataset Disney+ menggunakan **EDA**  
- Menganalisis pola distribusi konten menggunakan **statistik deskriptif**  
- Mengidentifikasi tren konten berdasarkan kategori, genre, negara, dan tahun rilis  
- Melakukan analisis inferensial menggunakan **Chi-Square Test** untuk melihat hubungan antar variabel kategorikal  
- Membuat visualisasi data untuk menemukan insight dari dataset Disney+
